# Markdown Syntax-Schnellstart

_Eine kurze Einführung in die wichtigsten Markdown-Funktionen_

Markdown ist eine einfache Auszeichnungssprache, mit der Sie formatierte Texte schreiben können. Hier sind die
wichtigsten Elemente:

## Zeilenumbrüche

In Markdown werden einfache Zeilenumbrüche im Fliesstext ignoriert.
Um einen Zeilenumbruch zu erzwingen, fügen sie zwei Zeilenumbrüche am Ende einer Zeile ein. 

So wie hier demonstriert.


## Überschriften

Verwenden Sie `#` für Überschriften. Je mehr `#`, desto kleiner die Überschrift:

# Überschrift 1

## Überschrift 2

### Überschrift 3

#### Überschrift 4

## Textformatierung

**Fettgedruckter Text** wird mit zwei Sternchen erstellt: `**fett**`

*Kursiver Text* wird mit einem Sternchen erstellt: `*kursiv*`

***Fett und kursiv*** kombiniert: `***fett und kursiv***`

~~Durchgestrichener Text~~ mit zwei Tilden: `~~durchgestrichen~~`

## Listen

### Ungeordnete Listen

Verwenden Sie `*`, `-` oder `+` für Aufzählungen:

* Erster Punkt
* Zweiter Punkt
    * Unterpunkt (mit zwei Leerzeichen eingerückt)
    * Weiterer Unterpunkt
* Dritter Punkt

### Geordnete Listen

Verwenden Sie Zahlen mit einem Punkt:

1. Erster Schritt
2. Zweiter Schritt
3. Dritter Schritt

## Links und Bilder

**Links:** `[Linktext](https://www.beispiel.de)`

Beispiel: [Besuchen Sie Google](https://www.google.de)


**Bilder:** `![Alternativtext](pfad/zum/bild.jpg)`

Beispiel: ![Logo](assets/logo.png)
